Introduction

Welcome to the NGC Components Library. A collection of premium, reusable design system UI components built for modern Angular applications. Easy to integrate, clean, and highly customizable.

Installation

Install the library package from your private registry or npm repository: 

npm install ngc-library

Quick Start

Import the global NgcModule (or import specific sub-modules) into your Angular application module: 

import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { NgcModule } from 'ngc-library'; // Import library
import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [
    BrowserModule,
    NgcModule // Add to imports
  ],
  bootstrap: [AppComponent]
})
export class AppModule { }

Styling

Add library stylesheets to your project's global stylesheet or angular.json configurations: 

/* styles.scss */
@import '~ngc-library/scss/index.scss';
