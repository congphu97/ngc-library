Textarea

Textarea is an input selector component supporting text area rows and column configurations. 

<ngc-textarea [label]="'Textarea'" [rows]="10" [cols]="10" (valueChange)="console.log($event)"></ngc-textarea>

Toast

Toast is a temporary notification message overlay supporting success, info, warning, and danger severity types.

Tooltip

Tooltip directive adds contextual popup text prompts upon hovering elements, supporting placements (above, below, before, after) and custom HTML content. 

<button ngcButton position="above" [ngcTooltip]="'Tooltip'">Tooltip Above</button>
<button ngcButton position="below" [ngcTooltip]="'Tooltip'">Tooltip Below</button>
<button ngcButton position="before" [ngcTooltip]="'Tooltip'">Tooltip Before</button>
<button ngcButton position="after" [ngcTooltip]="'Tooltip'">Tooltip After</button>
<button ngcButton position="below" [ngcTooltip]="tooltip">Tooltip Custom</button>

Alert

Alert component provides feedback messages for typical user actions, supporting color presets (primary, info, success, warning, danger), custom hex colors, leading icon configurations, and close triggers. It can be used both as an element (`<ngc-alert>`) or as an attribute directive (`[ngcAlert]`).
